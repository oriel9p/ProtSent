Most of this tree is raw per-run output. Five files carry the conclusions.

| Read this | For |

## SCOPe-40: three different protocols are in play

Reported numbers for the same model differ by protocol, so check which one a table uses before
comparing anything.

| Source | Level | Corpus | ESM-2 150M R@1 |
|---|---|---|---|
| Paper Table 3 | superfamily | "full validation set (100,000 proteins)" | 0.423 |
| `RESULTS.md` | **family** | `tattabio/scope40_test`, 2,207 domains | 0.5535 |
| `late_interaction/` tables | **superfamily** | `tattabio/scope40_test`, 2,207 domains | 0.7277 |

The two in-repo protocols agree with each other where they overlap (family-level MAP reproduces to
four decimals). **Neither reproduces the paper's Table 3**, which uses a 45x larger gallery — a
bigger gallery makes retrieval harder, which is the direction of the gap. Anything quoted against
Table 3 needs a rerun on that corpus first.
